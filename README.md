# 3D 인테리어 견적 시뮬레이터

대전 둔산동 국화아파트 604동을 표시명으로 사용하는 테스트용 가상 평면 기반 프로토타입입니다.

현재 프로토타입 기능:
- 브라우저 3D 공간
- 마우스/터치 회전 및 확대·축소
- 바닥, 벽, 주방, 중문 옵션 변경
- 낮/밤 및 조도 조절
- 우물천장 간접조명 옵션
- 옵션과 연동되는 예시 견적
- 네고 금액 반영
- 자연어 형태의 간단한 옵션 입력
- 모바일 반응형

주의: 표시되는 평면과 단가는 테스트용 예시이며 실제 국화아파트 604동의 정확한 도면이나 실제 시공 견적을 의미하지 않습니다.
